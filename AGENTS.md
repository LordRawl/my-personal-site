# Заметки для агента

## Политика прогонa тестов

Полный регресс (тест-скрипты + пересборка) выполняется **только после значительных изменений**. После мелких правок тесты НЕ гоняем — достаточно того, что код компилируется.

**Значительные изменения (тесты нужны):**

- логика интерактива: `useFullpageScroll.ts`, `useTheme.ts`, `useReveal.ts`;
- поведение форм/модалок (`ContactsSection.vue`, `ProjectModal.vue`);
- SEO/мета (`nuxt.config.ts`, JSON-LD, head);
- структура данных `app/data/*.ts`, влияющая на рендер;
- изменения конфигурации сборки/зависимостей.

**Незначительные изменения (без тестов):**

- тексты/копирайтинг без смены структуры данных;
- точечные стили/классы/Tailwind-утилиты;
- форматирование, комментарии, документация.

Если сомневаешься — спроси у пользователя, гнать ли тесты.

## Структура данных (после рефакторинга)

- `app/types/site.ts` — интерфейсы `Project`, `ExperienceItem`;
- `app/utils/period.ts` — `periodLabel` / `periodDuration` (автоимпорт из `utils/`, парсинг дат `DD.MM.YYYY`, склонения год/года/лет);
- `app/data/profile.ts` — профиль, навигация; `about.ts` — статистика и фичи; `skills.ts` — категории навыков, marquee; `projects.ts`; `experience.ts` (+образование); `contacts.ts`.
